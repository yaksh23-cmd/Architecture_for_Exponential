# Architecture_for_Exponential

## Features
- Developed a novel algorithm to compute the exponential function (exp(x)) optimized for 16-bit fixed-point
inputs, targeting efficient hardware implementation .
- The algorithm was designed to reduce computational
complexity while maintaining acceptable accuracy for embedded and FPGA-based applications.
- Implemented the design in Verilog and validated it using simulation and testbenches.
- Tools used: Xilinx Vivado,EDA Playground
